# Food Ordering Behaviour and Consumer Trends

## Project Overview

This project analyzes customer food ordering behaviour using Tableau. The objective is to understand customer preferences, ordering patterns, cuisine popularity, customer satisfaction, and business trends through interactive dashboards and visualizations.

## Tools Used

- Tableau Public
- Microsoft Excel
- CSV Dataset

## Features

- KPI Dashboard
- Order Analysis by Age Group
- Cuisine-wise Average Order Value
- Discount vs Repeat Orders
- Meal Type Heatmap
- Delivery Fee Analysis
- Customer Rating Distribution
- City and Restaurant Analysis
- Mood and Hunger Behaviour Analysis

## Dataset

Food Ordering Behavior Dataset (CSV)
